# CMI — Construcciones y Mantenimiento Integral

Sitio institucional de CMI: construcción, mantenimiento industrial y tratamiento de agua en Hermosillo, Sonora.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
